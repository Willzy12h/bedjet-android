# Nocturne v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A sideloadable APK that plans BedJet 3 nights around the next alarm, with remote, widgets, wake-up notification, snapshots and an update check.

**Architecture:** A pure-Kotlin `:core` module holds everything testable on the JVM: the BedJet 3 byte protocol, the plan compiler, wake resolution, the link/controller over an abstract transport, a simulated BedJet, backups and update parsing. The `:app` module is a thin Android layer: Bluetooth GATT transport, storage, a foreground service, alarm/notification plumbing, Compose UI and Glance widgets.

**Tech Stack:** Kotlin 2.0.21, AGP 8.7.3, Gradle 8.14.3, Jetpack Compose (BOM 2024.12.01, Material 3), Glance 1.1.1, kotlinx-serialization-json 1.7.3, kotlinx-coroutines 1.9.0, JUnit 5.11.3.

**Spec:** `docs/superpowers/specs/2026-10-21-nocturne-design.md`

## Global Constraints

- Package `io.github.willzy12h.nocturne`; app name "Nocturne".
- minSdk 31, targetSdk 35, compileSdk 35. JVM target 17.
- BedJet 3 only. Temperatures are stored in half °C everywhere; °C/°F is display only.
- Working slot default index 2 (slot 3). 3 slots, 32 steps per program, 15-char ASCII names.
- Max step 11 h 59 min; Turbo max 10 min; heat cut-off per Lull's table.
- Network only for the update check. No analytics.
- Every BedJet write goes through one serial queue; 5 s timeout per operation.

## Review Focus

1. Night started after the alarm's time window, or alarm within an hour → falls back to default wake time, never a negative Middle. (Task 3 test `wakeTooSoonUsesDefault`.)
2. Alarm moved earlier than Start + Wake-up → Start and Wake-up trimmed, plan still ends at the alarm. (Task 3 `shortNightTrimsStartThenWake`.)
3. Night crosses midnight / DST → clock-time step uses local wall time of the wake-up start. (Task 3 `clockTimeStepUsesLocalWallTime`.)
4. Restoring a snapshot from an older schema version → still loads. (Task 5 `loadsVersion1Bundle`.)
5. Slot write interrupted → read-back mismatch reports `VerifyFailed`, history notes it. (Task 4 `verifyFailsOnMismatch`.)

### Task 6: Android Bluetooth transport (`app/.../ble`)

**Files:** `AndroidBedJetLink.kt`.

Implements `BedJetLink` over `BluetoothGatt`: scan for service `00001000-bed0-0080-aa55-4265644a6574` or name prefix `BEDJET`, remember address, enable notifications on `…2000`, read `…2001` name, write `…2004` with response, read replies from `…2006` with the tag-echo retry (4 attempts), assemble partial status via read of `…2000` like Lull. All operations serialized with a `Mutex`, 5 s timeouts.

- [ ] `:app:assembleDebug` compiles. Commit `feat(app): Bluetooth transport`.
