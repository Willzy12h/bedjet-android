**Off identity contract (F1 clarification):** Off is identity-free for night/revision checks, including old notification/widget/dialog requests with `requireIdentity=true`: a stale night identity never blocks it. It remains bound to its captured selected BedJet 3. A selected-target change rejects the old request without writing; the exception never permits a target switch. Other identity-required commands retain their stale-night checks. This corrects the original Task 4 contract and the old R16 test reference below; the Off implementation and its existing regression assertions are unchanged.

**Off pending with an unreachable BedJet 3:** the UNKNOWN night remains tracked past `endsAt` while its matching `endRequested` is unresolved. Reconciliation retains that state when it cannot obtain fresh status; scheduled expiry does not close it. It stays tracked until a stopped-state report arrives from the selected BedJet 3 or the user taps **Stop tracking**, which only closes local tracking. A running-state report or a report from another target cannot confirm Off.
