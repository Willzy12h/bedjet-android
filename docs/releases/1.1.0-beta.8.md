## Nocturne 1.1.0-beta.8

**Upgrading from a public Nocturne beta?** Open `nocturne-1.1.0-beta.8.apk` from this release on your phone and choose **Update**. Keeping Nocturne installed preserves your profiles, selected BedJet, presets and settings. Review APKs use a separate test certificate, so Android refuses them as updates to public Nocturne.

Nocturne is an independent app for Android 12 or newer and the BedJet 3. It installs alongside the manufacturer's BedJet app.

### Remote and Tonight

- **Off** waits for a fresh standby report from the selected BedJet. If the connection drops, Nocturne tells you when it cannot confirm that the unit stopped.
- **Start night now** and quick presets can wait while the phone connects. You can cancel before a command is sent. If Nocturne finds an unexpected run on the unit, it asks before replacing it.
- **Remote** remembers temperature and fan changes once the BedJet confirms them. It recalls them separately for each unit and mode. **Finish at** lets you set the end time of a manual run.
- On **Tonight**, wider steps last longer, taller steps use more fan and colour shows the mode. Long heat is an editable quick preset in the bottom-left tile.
- Tonight identifies the wake source and lets you skip one scheduled start, with Undo. Releasing a BedJet for another phone lasts until you explicitly reconnect.

### Backups, Sleep and privacy

- Nocturne checks that it can restore the complete backup before writing it. Deleting a night also removes it from app-managed recovery snapshots. Files you exported earlier stay under your control.
- Sleep distinguishes separate sessions on the same day and shows gaps in BedJet observations.
- You can review the complete diagnostics file before saving it. The file uses aliases for BedJets, omits free-text notes and includes exact alarm times only if you select that option.
- Lock-screen Off is an opt-in on this phone. A shortcut that starts a night shows which BedJet and profile it will use. First run offers a choice of connecting your BedJet or trying the demo.
