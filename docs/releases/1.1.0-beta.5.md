## Nocturne 1.1.0-beta.5

A beta of Nocturne, a free, open-source Android app for the BedJet 3 that plans each night around your alarm. Please
report anything odd as an issue.

**Download:** `nocturne-1.1.0-beta.5.apk` below. Android 12 or newer and a BedJet 3 are required. See the
[README](https://github.com/Willzy12h/bedjet-android#download) for install steps and what each permission is for.

This beta includes everything in [1.1.0-beta.4](https://github.com/Willzy12h/bedjet-android/releases/tag/v1.1.0-beta.4),
so you can install it straight over any earlier beta.

### New in this beta
- Naps and short nights can end on your alarm again. Any alarm from an app you've ticked that is at least an hour after
  the night starts is used as your wake-up, whatever the time of day. This replaces the rule from 1.1.0-beta.3 that
  ignored an alarm less than 3 hours after bedtime.
- The other side of this: a stray alarm from a ticked clock app, such as a 23:00 reminder set in your clock, is used
  as your wake-up if it is an hour or more after the night starts. Tonight shows which alarm it will use before you
  start, and you can set a tonight-only wake time instead.
- The hour counts from when the night actually starts. An alarm set for an hour from now, with the night started a
  minute later, is less than an hour away, so the profile's wake time is used; set a tonight-only wake time for a nap
  that short.
- A night already running when you update keeps following its alarm.
