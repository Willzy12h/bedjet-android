## Nocturne 1.1.0-beta.6

A beta of Nocturne, a free, open-source Android app for the BedJet 3 that plans each night around your alarm. Please
report anything odd as an issue.

**Download:** `nocturne-1.1.0-beta.6.apk` below. Android 12 or newer and a BedJet 3 are required. See the
[README](https://github.com/Willzy12h/bedjet-android#download) for install steps and what each permission is for.

This beta includes everything in [1.1.0-beta.5](https://github.com/Willzy12h/bedjet-android/releases/tag/v1.1.0-beta.5),
so you can install it straight over any earlier beta. Your profiles, fan speeds, temperatures and settings stay as you
left them.

### New in this beta
- Reset to defaults. Each reset asks first. Restoring profiles and resetting controls also save a "Before reset"
  snapshot, which you can restore from Settings, Backups and snapshots.
  - **A built-in profile:** "Reset to default" in the profile editor puts back its built-in steps, temperatures,
    fan speeds, timings and name. The nights it's set for stay as they are, and nothing is saved until you tap Save.
  - **Profiles:** "Restore built-in profiles" puts back any built-in profile you changed or deleted. Profiles you made
    yourself are kept.
  - **Settings:** "Reset controls" puts the wake-up notification's buttons, Snooze, Extend, Boost and the Remote's
    quick settings back to how a new install has them. Your BedJet, alarms, theme and everything else stay as they are.
- A test build reminds you to export a backup in Settings. Moving between a test build and a release means
  uninstalling, which removes the app's saved data.
- After a fresh install, Tonight offers to restore your profiles and settings from a backup file.
- Every release is now checked to read the profiles, settings and backups saved by earlier betas.
