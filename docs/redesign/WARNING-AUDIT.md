## External Kotlin daemon diagnostic

The exact intermittent message is `w: Detected multiple Kotlin daemon sessions at ` (blank path). It appeared after aborted or compilation-failing runs, including `marker-menu-green` and `selection-history-green`, despite in-process compilation. The source is Kotlin Gradle plugin **2.0.21**, class `org.jetbrains.kotlin.gradle.plugin.KotlinGradleFinishBuildHandler`: `buildFinished(sessionsDir)` warns when it finds more than one `.salive` file in `.kotlin/sessions`, formats that directory relative to itself (the empty path), then deletes the markers itself. Decompiled evidence is retained as `kotlin-finish-handler.javap.txt`.

No warning filter or manual removal of session markers was used. Normal successful build completion performs the plugin's cleanup. The external diagnostic did **not** appear in the final clean gate or final 41-case capture run. Earlier appearances are retained in the run record rather than re-labelled as a project warning that was fixed. An older root Gradle problems report remains timestamped 01:48:16 UTC, before the final 04:19:21–04:41:38 UTC run; no new problem report or deprecation diagnostic was emitted by the final gate. That older report is not treated as a current result or deleted to make the result look clean.
